## What I'm working on

- **[domAIn](https://github.com/DiademShoukralla/domAIn/)**: a multi-agent "decision council" built with LangGraph. Three agents with different priorities (end-user experience, developer experience, and business/product fit) review the same proposal or PR against a shared knowledge layer: codebase, ADRs, and business docs, plus the roadmap from Linear, searched with hybrid retrieval. They can genuinely disagree, and the council writes its reasoning back as decisions through pull requests, so a human always reviews what becomes source of truth. Work in progress.
- **[Didi Build](https://didi.build)**: my independent practice helping founders who built with AI (Lovable, Bolt, Base44, Cursor) get their apps ready for real users, paying customers, and investors
- **External Brain Sync (EBS)**: a personal R&D project combining a natural-language interface, semantic + keyword search over an indexed codebase, and project management integration, so software work can be planned and delegated to AI agents
